# ICS4U

Grade 12 Computer Science. Units, handouts, visualizers, quizzes.

**Live study site:** https://vasiniks.github.io/ICS4U/

## Units

- **Unit 3 — Algorithms** (`unit-3-algorithms/`): BBC *Secret Rules of Modern Living*, Bubble (4 variants), Selection (in/out of place), Insertion, Counting (negatives, offset, money), Euclid GCD, fast powers, study guide, assignment details.
- Future units go in `unit-N-name/` folders with the same layout (source files + notes).

## Study site

Interactive guide (visualizations, homework answers, 48-question quiz) lives in `docs/` and deploys via GitHub Pages from `main` → `/docs`.

Run locally:

```bash
python3 -m http.server 8000 --directory docs
```
