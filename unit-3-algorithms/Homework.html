Euclid Algorithm

Two different algorithms for Euclid's Algorithm. Marcus demonstrated this in the BBC documentary using colourful square tiles on the floor. Both algorithms produce the same result.

ALGORITHM 1
function gcd(a, b)
    while b ≠ 0
        t := b
        b := a mod b
        a := t
    return a
ALGORITHM 2
function gcd(a, b)
    while a ≠ b 
        if a > b
            a := a − b
        else
            b := b − a
    return a

ALGORITHM 1
Input: a number x and a whole number n, where n is 1 or more.

Start with a result of 1.
Multiply the result by x.
Repeat step 2 until you have multiplied n times.
The result is x^n.
ALGORITHM 2
Input: a number x and a whole number n, where n is 1 or more.

1. Write down n.

2. If the last number written is 1, go to step 4. If it is even, write half of it. If it is odd, write one less than it.

3. Repeat step 2.

4. Start with x as your result.

5. Work back up your list. Each time the step was "half", square the result. Each time it was "one less", multiply the result by x.

6. When you reach n, the result is x^n.
